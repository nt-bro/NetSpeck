NetSpeck 1.0.3 — Windows 11 public preview
https://github.com/nt-bro/NetSpeck

ENGLISH
Extract the archive and run NetSpeck.exe. No installation or administrator
rights are required. The EXE is unsigned. Right-click the indicator or its tray
icon to open Settings; starting the app again also opens Settings.

Verified only on Windows 11 26H2 build 26300.9974 x64 with the standard primary
horizontal taskbar. Other Windows 11 builds are unverified. Windows 10 is not
supported. Read KNOWN_ISSUES.md before using this preview.

Numbers and the optional graph have independent smoothing. To resize, enable
Resize panel width in the menu and drag the left edge. Fonts, icons, colors,
units, startup and language are available in Settings. Hover over labels and
fields for explanations. Select Apply to save changes.

Preferences, imported assets and a bounded log stay in %LOCALAPPDATA%\NetSpeck.
There is no telemetry or automatic upload. Close the app before replacing the
EXE. If you move the EXE with startup enabled, disable/re-enable startup to
update its path. To remove: disable startup, exit the app and delete its folder;
you may also remove its LocalAppData folder if you do not need the preferences.

РУССКИЙ
Распакуйте архив и запустите NetSpeck.exe. Установка и права администратора
не нужны. EXE не подписан. ПКМ по индикатору или значку в трее открывает меню;
повторный запуск программы открывает настройки.

Проверена только Windows 11 26H2 26300.9974 x64 со стандартной основной
горизонтальной панелью задач. Работа на других сборках не подтверждена,
Windows 10 не поддерживается. Ограничения перечислены в KNOWN_ISSUES.md.

Сглаживание графика отдельно от усреднения чисел. Ширина меняется за левый
край после включения режима в меню. Параметры шрифтов, значков, графика,
единиц, автозапуска и языка находятся в настройках. Наведите на параметр
для пояснения. Для сохранения нажмите «Применить».

Настройки и свои файлы — в %LOCALAPPDATA%\NetSpeck. Автоматической отправки
данных нет. Перед обновлением завершите программу. При переносе EXE выключите
и снова включите автозапуск для обновления пути. Для удаления выключите
автозапуск, завершите программу и удалите папку приложения.
