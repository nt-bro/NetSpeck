# TaskbarNet 1.6.0 — Windows 11 public preview

Current download/upload speed inside the standard Windows 11 taskbar, with Russian and English UI.

## Download

Download **TaskbarNet-v1.6.0-win-x64.zip**, extract it and run **TaskbarNet.exe**. No installation or administrator rights are required. **Source code** archives are for building the app yourself. A SHA-256 checksum is attached as a separate file.

Features include independent number averaging and graph smoothing, an optional configurable background graph, left-edge width resizing, font and icon imports, optional startup, and explanatory tooltips. Two built-in icons are provided: Flows and Speedometer.

## Preview compatibility

Verified only on **Windows 11 26H2 26300.9974 x64** with the standard primary horizontal taskbar. Other builds are unverified; Windows 10 is unsupported. Integration is unofficial and Windows updates may affect it. The EXE is unsigned.

**Sleep/resume remains unverified:** a real S3 test froze the computer and required a manual reboot; the cause is unknown. Read [known issues](https://github.com/nt-bro/TaskbarNet/blob/main/docs/KNOWN_ISSUES.md).

The build passed 62 offline checks. Interactive development checks passed 114 behavior checks and 80 render cases. These results do not replace testing on your Windows build.
